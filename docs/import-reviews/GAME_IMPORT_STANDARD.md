# GameVado 开源游戏审核与原版移植标准

版本 1，2026-10-22。适用于商业广告网站候选、升级和已接入游戏。统一使用 [模板](GAME_IMPORT_TEMPLATE.md)；逐文件证据不足不得批准。先查授权，再做最小原版移植；不把简化重写、iframe 或启动截图冒充完整原版。

## 1. 候选登记与固定来源

记录官方项目名/权利人、仓库、分支、完整 commit SHA、获取日期、源码文件/归档 SHA-256、最后有效维护提交、最近 push、归档状态及浏览器 demo。push 日期不等于仍有人维护，演示可打开不等于源码功能齐全。核对同名仓库、官方链接和新旧版本，拒绝未溯源快照。

检查 README、全部许可证文件、文件级头部、依赖锁文件、嵌套压缩包、编译 bundle、资源目录和外链。获取失败依次试官方 HTTPS/git/官方 ZIP；记录错误，仍不可得则阻断，不造原版文件。只读审查安装脚本、工作流和 lockfile 后才安装；初次安装禁用 lifecycle，按需逐项批准必要脚本。不得上传生产密钥或调用原作者线上服务。

记录技术栈/引擎/构建工具、浏览器版本、客户端源码与打包资源、后端/数据库/登录/API/排行榜/多人服务、网络端点和离线能力。将必需与可选依赖分开；后端许可与数据使用权同查。

## 2. 许可与资源台账

复制模板中的字段；规模大时用 HexGL 同字段 CSV，**每个发行文件一行**，目录分组说明不能代替清单。包括不用但随 `public/` 暴露的文件和归档内部文件。字段：路径/哈希、来源 URL/SHA、作者和版权、主许可与例外、商业/修改/再分发条件、署名/全文/NOTICE/源码义务、证据位置、结论、问题/负责人。

核对仓库 LICENSE、README、package 声明与文件头是否一致。根许可不能覆盖明确例外或无权授予的第三方作品。混合文件逐段核查；压缩 bundle 展开组件清单，缺版本/缺许可为 UNKNOWN。没有许可证不等于公有领域。不能删除声明、更名或选择较宽松冲突条款绕过问题。

美术、贴图、模型、音乐、音效、字体、视频、翻译分别核查**精确版本**的原始作者页面、授权链和允许用途；截图/网络可下载不是授权。字体许可与商标、游戏名称/人物形象/肖像权分开。CC BY 保留作者、许可链接及改动标识；CC BY-NC 不通过当前商业用途；ND/SA 等条件逐项判断。公有领域/CC0 要留精确来源证据；现代字体或素材包许可不自动覆盖旧二进制。来源不明标 UNKNOWN，取证或经批准替换，发布前仍未知即阻断。

| 许可 | 商业使用与必须完成的合规动作 |
| --- | --- |
| MIT / BSD | 通常允许，按具体版本保留版权、许可/免责声明；BSD 条款差异逐项查 |
| Apache-2.0 | 保留许可、相关版权/归属及提供的 NOTICE，修改文件显著标记；核对专利/商标条款 |
| GPL | 允许商业；分发原版保留条款，修改作品标注修改/日期并按适用 GPL 提供；浏览器 JS/二进制交付按版本履行完整对应源码、构建/安装资料及取得方式要求；不能加不兼容限制。明确独立聚合与衍生/链接边界，不擅自宣布整站须 GPL 或整站豁免 |
| AGPL | 除相应 GPL 义务，还核查第 13 条：修改版本通过网络与用户交互时，显著提供取得该版本对应源码的机会；逐项记录服务、修改范围及提供方式，不能笼统称“只托管不分发就没义务” |
| MPL-2.0 | 文件级 copyleft；修改 Covered Software 文件按 MPL 提供源码并保留通知；可把独立新文件放在 Larger Work 的其他许可下；给浏览器压缩 JS 时落实对应源码取得说明。不能据根 MPL 自动给独立音乐/翻译授予权利 |

依据：[GPLv3 官方项目所附全文及 §§4–6、10](https://github.com/graememcc/micropolisJS/blob/f13a1624d111d235e804bd80f48ba7c9f66a8e0f/COPYING)、[AGPLv3 §13 法律文本的 SPDX 副本](https://github.com/spdx/license-list-data/blob/main/text/AGPL-3.0-only.txt)（GNU 页面本次请求超时，使用标准许可数据库副本核读）、[MPL-2.0 §§1、3](https://www.mozilla.org/en-US/MPL/2.0/)、[Mozilla FAQ 的 JS/文件范围说明](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)、[Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0)。以实际版本/完整条款为准；复杂组合及额外限制交负责人/法律审核，允许商业不代表无条件兼容 GameVado 专有代码。

条目结论 `LICENSE_VERIFIED` / `UNKNOWN` / `BLOCKED` 与项目工作流分开；UNKNOWN 需要补证，不自动宣称禁止但不能放行。记录证据获取日期、文件 SHA、内容哈希和未解决事项，远端变更后按新 SHA 重审。

## 3. 可移植性与工期评估

先确认完整原版能否运行、静态输出是否足够。列出必需文件、相对/绝对路径、动态 import、fetch、CORS、WebGL/Canvas、音频手势策略、存档/IndexedDB/Service Worker、性能及手机/键盘/手柄差异。原引擎/模型/贴图/音频/地图/AI/模式按清单保留。旧 API 优先最小兼容补丁，记录原因和原版差异；不擅自换资源或大改引擎。

Next.js 接入需核对 `public/play/<slug>/`、尾斜杠/base 路径、动态路由冲突、middleware/proxy、CSP/headers、静态资源 MIME、缓存、构建输出体积。保持原生 HTML 启动，不默认改写 React 或嵌 iframe。独立审核注册表与默认关闭 gate，同时覆盖详情、游戏入口、深层资源、压缩包；不进入首页/搜索/sitemap/相关推荐。flag 本身不是身份认证，审核只在本地/受控环境，生产不得意外开启。

估时分别记录授权取证（外部等待不承诺日期）、源码获取/安全、原版导入、接入补丁、玩法和跨设备测试、合规包/人审；给人日范围、假设、信心和阻断依赖。无法保留原版应说明具体原因及替代项目，不以简化版结项。

## 4. 可复用执行与发布闸门

1. 检查仓库路径、当前分支、未提交修改；保存事实，不覆盖用户工作。固定审核分支/基线，获取并锁定官方 SHA。
2. 完成许可初审及素材/依赖/外部服务清单。核心 BLOCKED 时只在允许范围取证，不能以“先上线再补”处理；UNKNOWN 发行物必须补证。
3. 审查锁文件和生命周期脚本，隔离安装、依赖漏洞/恶意端点/密钥/追踪检查；审计命令失败或未运行如实记录，不把静态阅读写成安全通过。
4. 导入完整原版并建立路径/大小/SHA-256 manifest；检查缺失、附带归档、仅允许的补丁；记录每个修改文件、原因及许可影响。
5. 执行原版提供的 check/smoke/build 与宿主生产构建。没有原版命令记 N/A；缺 Chrome/系统依赖先解决，无法解决标 BLOCKED，禁止虚报。
6. Playwright 在实际生产服务测菜单/加载/WebGL或Canvas、核心操作、碰撞/计分/胜负/结束/重开/退出、音频及控制台/失败请求；验证默认关闭时详情/入口/资源均不可达且目录/sitemap无条目。记录版本、命令、退出码、截图/报告；模拟/传送/辅助步骤明确标注，不能替代全流程人审。
7. 人工验收完整玩法、主要设备/性能、广告/SEO不回归；复核许可证/源码提供/完整通知/商标/素材权利链。
8. 技术与授权负责人分别签字后，进入 READY_FOR_RELEASE；独立记录发布人批准、时间、目标环境、回滚提交和 gate 改动。获得本次发布授权后才单独实施公开/生产部署，发布后验证再记 PUBLISHED。

测试表必须含日期、环境、命令、真实结果、证据、局限；区分历史通过/本次重跑/未运行/N/A。文档改动无需假装重跑 WebGL，源文件或依赖变更需相应回归。

## 5. 统一工作流状态

| 状态 | 进入条件 |
| --- | --- |
| DISCOVERED | 已找到候选及可追溯来源 |
| AUDITING | 正在核对版本、许可与技术 |
| BLOCKED | 有明确阻断或发布必需证据/依赖缺失，列负责人和解除条件 |
| READY_FOR_PORT | 来源、预定发行范围与许可证已足以批准移植，技术可行；不等于批准公开 |
| IMPLEMENTED | 已完整接入并记录差异，尚未完成所有测试 |
| TECH_VERIFIED | 规定技术检查真实通过，记录未覆盖范围 |
| LICENSE_VERIFIED | 发行范围内授权、通知、源码义务及名称等复核通过 |
| READY_FOR_RELEASE | 技术和授权同时通过，等待显式发布审批 |
| PUBLISHED | 已获批准、实际发布并验证生产结果 |

状态不是强制单线：保留 `overall_status`、`technical_status`、`license_status` 三字段；例如 HexGL overall=BLOCKED、technical=TECH_VERIFIED、license=BLOCKED。技术通过不能直接进入 READY_FOR_RELEASE。新 SHA/新增素材/许可冲突/外部服务变化会撤销相关通过状态并重新审查。

正式发布审批清单：来源固定；全部发行文件可追溯；零未解决 BLOCKED/UNKNOWN；所有通知/源码包就绪；技术回归和人工验收有证据；无未授权外部服务；目录/SEO/广告变更审批；明确发布者签字与回滚方案。缺任一项保持关闭。
